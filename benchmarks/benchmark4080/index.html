What is measured

Every pipeline runs its built-in generation preset with the same fixed prompts and a deterministic seed (42 for Cold, 43 for Warm). Image pipelines render a single frame. Video pipelines render landscape at 24 fps.

The same checkpoints are run on the same machine. Speedup is calculated as ComfyUI time / Nox time; above 1x means Nox was faster. Diffusion transformers use INT8 ConvRot except SDXL, which uses FP16.

Each SSIM compares the saved Nox and ComfyUI Warm outputs at that output size (seed 43). Image scores use all RGB pixels; video scores average nine evenly spaced decoded frames. Higher SSIM means closer outputs.

Known issue: ComfyUI High outputs for Qwen Image and Qwen Image Edit are black because SageAttention produces NaN on these models, so their High SSIM is near zero.

All Low runs use the default attention available. High uses SageAttention in both engines. ComfyUI runs all Low cases, then restarts once with SageAttention for all High cases; each High case is warmed with a small seed-42 run before its seed-43 Warm run. Nox runs each pipeline’s High case right after its Low case with weights loaded.

MiniMax-H3 is the sparse-attention exception: Nox High uses SageAttention with 15% sparse key density, one dense leading step and the first layer dense, while ComfyUI High uses Veda’s trained sparsity.

Both totals sum the recorded Cold and Warm runs. The ComfyUI total excludes its small High warmup runs, which only reload models after the SageAttention restart; Nox needs no restart and has no equivalent run.

Peak VRAM is the highest value across a pipeline’s jobs, reported using each benchmark’s native measurement method: actual device usage for ComfyUI and tracked allocation peak for Nox. Nox keeps models loaded in VRAM until the memory is needed for something else, instead of freeing it after every generation. On GPUs with more memory its peak therefore rises toward the available VRAM; this avoids reloading models and does not reflect the minimum a pipeline needs to run.
