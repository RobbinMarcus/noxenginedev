NOX ENGINE

Built for image and video inference

Specialized INT8 execution

INT8 ConvRot is a form of quantization that uses 8-bit integers for model execution and targets near-BF16 quality. Nox is built to execute these quantized models as fast as possible on NVIDIA GPUs for image and video generation.

Plan first. Execute exactly.

Nox plans execution and GPU memory use before generation, then executes that plan exactly. Available VRAM and model offloading are accounted for in advance, keeping memory use predictable across the pipeline.
